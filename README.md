# Disbursement assignment

This is a simple assignment to practice the "requirement → spec" process. Use your agentic coding skills to create a spec for a disbursement system and implement until it is working for both the frontend and backend.

# Requirements
> Save in `docs/`, create if not exists
• Auto-generate System Analysis: Input meeting note, email or transcript and let Claude Code summarize it into functional/non-functional requirements
• ER Diagram & Data Dictionary (Save as
• Tech Spec / SRS: Draft a system specification document with a clear structure
• Flag assumptions: Let Claude identify missing or ambiguous requirements instead of guessing — reduce scope creep
